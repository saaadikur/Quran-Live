## প্রজেক্ট পরিচিতি ও উদ্দেশ্য (The Vision)"</strong>




আজকের সোশ্যাল মিডিয়া নির্ভর যুগে আমাদের মনোযোগ বা 'Focus' ধরে রাখা সবচেয়ে বড় চ্যালেঞ্জ। বিশেষ করে যারা দীর্ঘক্ষণ পিসিতে কাজ করেন, তারা প্রায়ই অজান্তেই বিভিন্ন বিনোদনমূলক সাইটে সময় অপচয় করে ফেলেন। 

**Quran Live** প্রজেক্টটির মূল লক্ষ্য হলো:
*   **আসক্তি মুক্তি:** সোশ্যাল মিডিয়া বা অনর্থক বিনোদনের বিকল্প হিসেবে একটি আধ্যাত্মিক পরিবেশ তৈরি করা।
*   **ডিপ ওয়ার্ক (Deep Work):** কোডিং, ডিজাইন বা যেকোনো প্রোডাক্টিভ কাজের সময় ব্যাকগ্রাউন্ডে পবিত্র কোরআনের তিলাওয়াত ও অনুবাদ শোনার সুযোগ করে দেওয়া।
*   **সহজ লভ্যতা:** কোনো বিজ্ঞাপন, ট্র্যাকিং বা জটিলতা ছাড়াই সরাসরি পবিত্র কোরআনের বাণীর সাথে যুক্ত হওয়া।

## ✨ মূল বৈশিষ্ট্যসমূহ (Core Features)

- 🎧 **অডিও স্ট্রিমিং (প্রাথমিক):** উর্দু অনুবাদসহ চমৎকার তিলাওয়াত শোনার ব্যবস্থা।
- 🇧🇩 **বাংলা অনুবাদ (শীঘ্রই):** খুব দ্রুত বাংলা অনুবাদ এবং তিলাওয়াত যুক্ত করা হবে।
- 🚫 **বিজ্ঞাপনমুক্ত ইন্টারফেস:** সম্পূর্ণ বিশুদ্ধ অভিজ্ঞতা, কোনো প্রকার ডিস্ট্রাকশন নেই।
- 💻 **মিনিমালিস্ট ডিজাইন:** অত্যন্ত হালকা এবং দ্রুতগতির ওয়েব ইন্টারফেস।
- 📱 **রেসপন্সিভ:** পিসি এবং মোবাইল—উভয় ডিভাইসেই অনায়াসে ব্যবহারযোগ্য।

## 🤝 কন্ট্রিবিউশন (Contribution Guide)

এটি একটি সওয়াব-এ-জারিয়া এবং ওপেন সোর্স প্রজেক্ট। আপনি যদি এই যাত্রায় একজন ডেভেলপার হিসেবে অবদান রাখতে চান:

1. প্রথমে রিপোজিটরিটি **Fork** করুন।
2. আপনার নতুন ফিচার ব্রাঞ্চ তৈরি করুন: `git checkout -b feature/NewAmazingFeature`
3. আপনার পরিবর্তনগুলো **Commit** করুন: `git commit -m 'Added some amazing feature'`
4. ব্রাঞ্চটি **Push** করুন: `git push origin feature/NewAmazingFeature`
5. একটি **Pull Request** ওপেন করুন।
